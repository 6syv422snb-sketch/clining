# Лендинг: уборка после ремонта и регулярный клининг бизнеса

Статическая страница без сборки: `index.html` + `privacy.html`. Заявка с формы уходит в
Google Apps Script, который пишет её в Google Таблицу и сразу присылает в Telegram вместе с фото.

## Запуск за 20 минут

1. **Telegram-бот.** В @BotFather создайте бота (`/newbot`) и сохраните токен. Напишите боту
   любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите
   `"chat":{"id":...}` — это ваш `TELEGRAM_CHAT`.
2. **Таблица.** Создайте пустую Google Таблицу и скопируйте её id из адреса
   (`docs.google.com/spreadsheets/d/<ID>/edit`). По желанию создайте папку на Диске для фото (её id — в адресе).
3. **Скрипт.** В таблице: Расширения → Apps Script. Вставьте код из `apps-script/Code.gs`.
   В Project Settings → Script properties добавьте `TELEGRAM_TOKEN`, `TELEGRAM_CHAT`, `SHEET_ID`
   и, если нужно, `FOLDER_ID`. Запустите `testNotify` — выдайте разрешения, в Telegram придёт тестовое сообщение.
4. **Публикация скрипта.** Deploy → New deployment → Web app; Execute as: **Me**; Who has access: **Anyone**.
   Скопируйте URL вида `https://script.google.com/macros/s/.../exec`.
5. **Настройки страницы.** В конце `index.html` заполните блок `CONFIG`: название, реквизиты,
   телефон, Telegram, WhatsApp, `endpoint` (URL из шага 4) и пути к своим фото «до/после».
6. **Хостинг.** Подойдёт любой статический: GitHub Pages, Netlify, Яндекс Object Storage, Tilda (блок HTML).
   Заполните `privacy.html` — без политики и согласия собирать телефоны нельзя (152-ФЗ).

После изменений в скрипте делайте Deploy → Manage deployments → Edit → New version, иначе
будет работать старая версия.

## Что уже учтено

- **Цена до выезда.** В тексте закреплены фиксированная предварительная стоимость по фото
  и защитная оговорка про несоответствие фото.
- **Калькулятор в форме.** Показывает ориентир сразу: 180 ₽/м², для сильно загрязнённых 220–250 ₽/м²,
  минимальный заказ 5 000 ₽, окна по 300–500 ₽ за створку. Для офисов — 30–45 ₽/м², от 4 500 ₽ за выезд.
- **Мобильная версия в первую очередь.** Внизу закреплена панель «Рассчитать / Позвонить / Telegram».
- **UTM-метки** и `yclid` пишутся в таблицу, чтобы понимать, какая реклама приводит заявки.
- **Защита от спама.** Скрытое поле и минимальное время заполнения формы.
- **Фото** сжимаются в браузере до 1600 px, отправляется до 5 штук.

Цель для Яндекс Метрики: подключите счётчик и задайте `window.YM_ID = <номер>` — при отправке
формы сработает цель `lead`.

## Тест ниши без фото

- Блок «до/после» скрыт, пока `CONFIG.photos` пуст: стоковые фото снижают доверие, поэтому лучше без них.
- Под каждый оффер — своя ссылка для рекламы. Так в таблице будет видно, какой оффер даёт заявки:
  - `…/index.html?offer=renovation&utm_campaign=remont` — после ремонта;
  - `…/index.html?offer=office&utm_campaign=office` — офисы.

  С `?offer=` меняются заголовок и порядок кнопок, открывается нужная вкладка, а в форме заранее выбран тип уборки.
- Что считать: стоимость заявки, долю заявок, где удалось назвать цену, и долю «дорого»
  по каждому офферу и городу. Статус заявки ведите в столбце «Статус» таблицы.

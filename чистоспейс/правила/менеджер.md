# Плейбук менеджера ЧистоСпейс: холодные письма

Автор: София (агент-менеджер). Действует вместе с `правила/0-продукт.md`: продукт, цены, обещания,
«Условия для партнёров» и «Доказательства» берутся только оттуда. Здесь — как писать.
Если правило ниже расходится с `0-продукт.md` или с указаниями владельца — побеждают они.

## 1. Что говорят данные (и насколько им верить)

| Вывод | Источник | Надёжность |
|---|---|---|
| Короче — лучше: пик ответов у писем 20–39 слов; у лучших отправителей (10%+ ответов) письма короче 80 слов | Hunter (34 млн писем), отчёт Instantly 2026 | средняя: данные сервисов рассылок, причинность не доказана |
| 75–100 слов — верхняя граница: письмо целиком помещается на экран телефона, а B2B-письма чаще всего сначала открывают с телефона | обзоры HubSpot / FullEnrich (вторичные) | средняя |
| Первое письмо даёт ~58% всех ответов, остальное — напоминания; 3–5 касаний примерно вдвое лучше, чем без напоминаний (8,3% против 4,1%) | Instantly 2026 | средняя |
| Первое напоминание — через ~3 дня, всё касание укладывается в 2–3 недели | Smartlead, обзоры по последовательностям | средняя |
| «Просто напоминаю» не работает: каждое касание обязано нести новую пользу | разборы последовательностей (echai.ventures, Josh Braun) | высокая по согласию источников |
| Читателю нужно за секунды понять одну конкретную причину ответить | Lavender (231 818 писем) | высокая |
| Для клининга: зацепка — конкретное здание/событие (ремонт, новый арендатор, переезд, сезон); тема как от коллеги, 4–7 слов; без «Re:» в первом письме, без ложной срочности | Abstrakt MG (отраслевой блог) | низкая–средняя: мнение практика |

Средний отклик на холодные письма — около 3–4%, у лучших — 10%+. Цель — быть среди лучших за счёт точности, а не объёма.
Свои цифры важнее чужих: после 20–30 отправленных писем сверяем, что работает у нас, и правим этот файл.

## 2. Почему отвечают (пять причин)

1. **Про них, а не про нас.** Первая строка — проверяемый за минуту факт из разбора: их объект, их событие, их отзыв клиентов.
2. **Одна боль — одна услуга.** Не каталог. Одна услуга, одна польза для этого получателя.
3. **Цена сразу и честно.** «От … ₽» с сайта. Скрытая цена в клининге читается как «будет дорого».
4. **Шаг, который делается за 30 секунд.** «Пришлите фото ближайшего объекта — назову точную цену за 15 минут». Не звонок, не встреча.
5. **Похоже на письмо человека.** Без шаблона, без «динамично развивающейся компании», без вложений и картинок.

## 3. Железные правила письма

- **Канал:** почта. Telegram — только если почты нет, с пометкой «канал: Telegram (почты нет)» в файле письма.
- **Обращение:** на «вы», по имени-отчеству, если оно есть в досье; иначе «Здравствуйте!». Без англицизмов
  (не «кейс», «фидбэк», «оффер», «апдейт», «лид»: говорим «пример», «отзыв», «предложение», «новость»).
- **Город:** только Санкт-Петербург. Казань и Екатеринбург не упоминаем.
- **Тема:** их ситуация одной строкой, 3–7 слов, строчными, как от коллеги.
  Нельзя: «сотрудничество», «предложение», «выгодно», капс, «!», «Re:» в первом письме, ложная срочность.
  Хорошо: «Уборка после ремонта на Литейном», «Сдача квартир на Звёздной».
- **Состав (80–100 слов максимум, лучше 50–80):**
  1. Зацепка из разбора — один проверяемый факт о них.
  2. Одна услуга и её польза именно для них (их время, их сроки сдачи, их отзывы клиентов).
  3. Цена «от» с сайта, из `0-продукт.md`.
  4. Не больше одного условия из «Условий для партнёров» — и только если оно уместно.
  5. Один простой следующий шаг.
  6. Подпись.
- **Нельзя:** абзац о себе; цифры опыта, отзывы, портфолио, которых нет в «Доказательствах»; обещания, которых нет в
  `0-продукт.md`; больше одного вопроса; вложения и ссылки, кроме сайта в подписи.
- **Повторный лид** (в «Касаниях» уже есть 1-е): не извиняемся, не ссылаемся на прошлое письмо, пишем как новое, с новой зацепкой.
- **Закон:** письмо — личное деловое предложение конкретному адресату, а не массовая реклама (38-ФЗ, ст. 18).
  Пишем только на рабочие адреса из открытых источников, каждое письмо — своё. На «не пишите больше» — сразу статус
  «отказ» и больше не пишем.

**Подпись (дословно):**

```
София, менеджер ЧистоСпейс
chistospace.info@gmail.com · Telegram @chistospace
https://chistospace.netlify.app/
```

## 4. Касания

| # | Когда | Что внутри | Длина |
|---|---|---|---|
| 1 | день 0, будни 9:00–11:00 или 14:00–16:00 по Петербургу | основное письмо | 50–100 слов |
| 2 | через 3–4 дня | новая короткая польза: другая грань той же боли (сроки сдачи, отзывы жильцов/клиентов, сезон, чек-лист приёмки) | 30–50 слов |
| 3 | через 7–10 дней после 1-го | ещё одна польза или вопрос «да/нет» + лёгкий выход: «если неактуально — так и напишите, больше не побеспокою» | 25–40 слов |

- Напоминания отправляются ответом в ту же цепочку (тема сохраняется) — это не «Re:» в первом письме.
- Нельзя: «напоминаю о письме», «вы, наверное, не увидели», «хотела уточнить, получили ли».
- После 3-го касания без ответа — статус «тишина». Через 2–3 месяца можно вернуться с новой зацепкой, как к новому лиду.
- Пятница после 15:00, выходные и праздники — не отправляем.

## 5. Заготовки ответов (принципы)

В каждом файле письма заготовки подгоняются под лида. Общий подход:

- **«Сколько стоит?»** — назвать «от …» из `0-продукт.md` и сразу объяснить, от чего зависит; попросить фото и площадь → точная цена за 15 минут, фиксируем до выезда.
- **«Пришлите примеры работ»** — давать только то, что есть в «Доказательствах». Если там пусто — честно: «Мы молодая команда, фото чужих объектов не показываем.
  Предлагаю проверить на деле: …» + условие для первого объекта из «Условий для партнёров», если оно есть.
- **«Дорого»** — уточнить, с чем сравнивают; разложить, что входит; предложить уменьшить объём (без окон, только санузлы и кухня), а не снижать цену. Скидку — только из «Условий для партнёров».
- **«У нас уже есть уборщица / свои люди»** — не спорить. Предложить нас на то, что штатный человек не делает: уборку после ремонта, генеральную перед сдачей, подмену в отпуск, срочный объект.

## 6. Статусы в `ЛИДЫ.md`

`разобран` → (София пишет) `письмо готово` → (после «отправляй») `отправлено` + дата в «Касания» →
напоминания: дата 2-го, 3-го касания → `тишина` после 3-го без ответа. Ответили — `ответ`, отказались — `отказ`.
